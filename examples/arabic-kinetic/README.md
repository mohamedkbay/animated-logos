# Arabic kinetic study

An original six-device motion example, 18 seconds, 540×960 at 30 fps, silent. All explanations and controls are English. Arabic is retained only as the connected-letter specimen.

Open `index.html` to play or seek the deterministic scene. Edit `plan.js` to customize the palette, words, connector guide, counter or demo identity. Keep `engine.js` and the licensed font beside it.

The [recipe and run commands](../../skills/animated-logos/references/arabic-kinetic.md) explain each technique and its current limits. The supplied reference movie and soundtrack are not part of this example. Cairo font software is OFL; see `FONT-LICENSE.txt`. Original code/artwork is covered by the repository MIT license.
